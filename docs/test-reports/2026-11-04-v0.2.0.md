## 测试中发现并修复的问题

1. 透明交互区域覆盖碎菜和工厂零件，导致可见物件拖不动。已移除重复覆盖层并拆分整菜/碎菜对象。
2. 相机移动后用指针坐标判断落点不稳定。已改用被拖动物件的世界坐标。
3. 刷新前保存了暂停状态，新页面可能永久暂停。启动时现在按真实页面可见性重置临时暂停值。
4. 低帧率下 Phaser 平滑时间导致烹饪变慢。统一时间轴已改用 `performance.now()` 的真实在线间隔。
