# v0.3.0 清新二次元改版测试

## 验证结果

- TypeScript 类型检查、正式构建通过。
- Vitest 共 13 项测试通过，包含熟食超时烧糊、持续房屋攻击、夜间血月等回归。
- 既有 4 个浏览器场景全部通过：四种屏幕尺寸、农田与刷新读档、厨房完整交互、出餐至建塔。
- 新增全新存档真实触摸场景单独运行通过（2.3 分钟）：不注入资源、不设置教程进度，使用 CDP touch 事件完成收获播种、跨场景烧糊、清理重做、出餐、工厂切焊装配、初始信标、两只教学僵尸、正式维修、造塔、上路放塔以及刷新读档。
- 单文件离线资源测试通过：拦截全部外部资源请求后仍可显示、滑动至农田、收获并保存，无脚本异常。

## 诊断过程

第一次并行运行浏览器场景时，新增长流程在建塔截图后等待自动保存处超过 150 秒测试上限，其余 4 项通过。中断自动重试后，将完整流程时限调整为 240 秒并单独执行，所有步骤与断言保留，重跑通过。浏览器配置固定为单 worker，避免录屏和截图竞争资源。

## 存档与资源

- 继续使用 v1 存档格式；`turretLane` 为可选字段，旧存档沿用中路，新建塔保存真实选择。
- 更换全部背景、角色、僵尸、炮塔、物件，新增独立厨具图集。
- 源图集保留于 `assets/source`；生产切片位于 `public/assets`；旧版本可通过既有 Git 标签恢复。
