# v0.3 美术与操作改版

用户于 2026-11-06 明确要求取消原开发版的土黄色废土风，采用更精致、可偏二次元的手游画面。本次更换原开发版视觉；无金币、十字世界与玩法规则按手册继续实施。

## 已实施方向

- 五个场景统一为蓝天、白墙、蓝色屋顶、薄荷绿设备和粉色花园；避免锈迹、褐黄滤镜和落日底图。
- 原创二次元幸存者、喜剧化僵尸、白蓝炮塔、鲜艳食材与银色机械零件。
- 白色半透明状态栏、青绿色文字、圆角提示和呼吸高亮，引导玩家辨认真正可操作的物件。
- 厨具采用独立绘制的锅、砧板、备菜碗、成品柜；可交互位置和显示位置保持一致。
- 工厂零件的切割、焊接、装配位置重新对齐台面，补充场景内短标识。
- 防线底图改为三条横向道路，配合现有横向敌人移动；建塔位置记录并在读档时恢复。

## 资源说明

`assets/source/` 保存原创生成图集，`public/assets/` 保存运行用切片。未使用商业游戏素材。当前是新风格的可玩开发版，仍需后续逐步精修角色动作帧、连续场景衔接和正式音效；不能将生成底图或静态角色视作最终美术验收。

## 操作和规则修复

- 修正农田回前台的滑动方向，并为每个外围场景写清返回手势。
- 厨房依据拿菜、切配、入碗、下锅、装盘、入柜的实际阶段提供一句提示及对应高亮。
- 熟食继续计时，超过阈值会糊；已装盘但未存柜时不会被第二份料理覆盖，备菜碗满时也不会吞掉碎菜。
- 教学阶段禁止提前投料工厂，保护初始材料。
- 炮塔按实际放置基座出现，旧档缺失位置时沿用原来的中路。
- 血月只在第七日夜间生效，信标追加威胁次日才参与刷怪间隔；贴近房屋的敌人持续攻击。
