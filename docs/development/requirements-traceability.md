# 《末日小院》需求追踪与代码差距

基准文档：`docs/design/末日小院_216项整合开发手册_v1.0.pdf`。本表按手册章节拆分需求；手册明确说明它是 216 项决定的系统化整合，不是 1～216 的逐题原文，因此不伪造不存在的逐题编号。

## 当前最高优先级差距

1. 补齐长期生存：多种敌人、炮塔耐久、维修、枪械弹匣、陷阱和完整血月。
2. 增加多作物、多菜谱、工厂队列及设备升级，让 20～30 分钟内容不重复。
3. 制作角色动作、作物生长、切菜、烹饪、射击、受击等正式动画和分类音效。
4. 在 iPhone Safari 与 Android Chrome 真机完成尺寸、性能、后台和音频验证。
5. 完成 20～30 分钟计时试玩，并修复所有阻断问题。
