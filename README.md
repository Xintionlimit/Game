# 末日小院

《末日小院》是一款手机竖屏 H5 游戏。当前仓库是正式开发基线，设计以 `docs/design/末日小院_216项整合开发手册_v1.0.pdf` 为准。

## 当前状态

- `v0.4.0` 在新手闭环后继续提供出餐、三路布防、信标升级、自动设备、维修与求救目标。
- 厨房清除了背景中的重复器具；真正可操作的厨具、刀具动作、蒸汽和成品柜状态单独渲染。
- 五个场景具有匹配的夜间背景、窗灯和星空，统一切换昼夜。
- 五个场景位于同一个连续十字世界，支持手机拖动跟手、吸附和回弹。
- 已有统一在线时间、后台暂停、昼夜/血月基础、版本化本地存档和信标检查点。
- 已有切菜、加工、命中、击倒、出餐、信标反馈及原创合成音效，支持关闭音效和手动暂停。
- 本版仍不等于手册全部最终内容；更多作物菜谱、角色逐帧动作、最终美术与真机验收继续跟踪。

## 继续经营

- 顾客白天到访，夜里可以备餐和整理防线；食物只在亲手交付时扣除。
- 工厂完成教学后可选信标零件、炮塔、维修工具、自动切菜和自动灌溉。选择后仍需把废料拖到加工台，取消会返还材料。
- 点击信标查看下一阶段所需的伙伴和零件，修复后开启设备图纸；顶部始终显示下一目标。
- 每条防线可放一座自动炮塔；点击受损炮塔使用工具维修，点击院门可维修房屋和路障。维修要经过六秒有效游戏时间。
- 手枪后备弹药不限，有弹匣和换弹；按住敌人持续射击。第七夜血月期间压力增大。
- 自动切菜和浇水只代替重复操作，不会替玩家选食材、排产或出餐。

## 开发命令

```bash
npm ci
npm run dev -- --host 0.0.0.0
npm run check
```

需要单文件试玩时运行 `npm run build:standalone`，产物是 `dist-standalone/末日小院-直接打开玩.html`，内置运行脚本、样式和全部图片。手机系统的 HTML 文件预览可能禁用脚本，在线网址仍是手机分发的推荐方式；单文件版不能替代 iOS/Android 真机验收。

`npm run check` 会检查类型、运行规则测试、生成发布构建，并用真实 Chromium 完成手机尺寸、滑动、农田、厨房及核心闭环操作。只有该命令通过后才能提交和推送。

长时间验收：先运行正式构建的 `npm run preview -- --host 127.0.0.1 --port 4173`，再运行 `node scripts/qa-long-play.mjs`。默认以真实时间操作22分钟；脚本只能读取观察接口，通过触摸实际改变游戏，不直接写资源、进度或游戏时钟。

存档由 v1 自动升级到 v2，保留原资源、炮塔位置和信标检查点；主档损坏时尝试有效备份。环境禁止保存时会提示“存档受限”，避免空白崩溃或假称已经保存。

## 手机试玩发布

`main` 通过全部检查后，GitHub Actions 会生成并部署静态 H5 构建。仓库首次启用时，需要在 GitHub 仓库的 `Settings → Pages → Build and deployment → Source` 选择 `GitHub Actions`。

## 版本安全

- `main` 只接收已通过检查的修改。
- 每次开发完成后更新 `CHANGELOG.md`，提交并推送到 GitHub。
- 可发布的稳定里程碑使用 `v主版本.次版本.修订号` 标签，例如 `v0.1.0`。
- 不改写 Git 历史；发现问题时通过新提交修复，或从稳定标签恢复。
- 大型美术源文件、无损音频和视频由 Git LFS 保存。

换电脑时，开发代理应获取 `main` 最新内容、安装锁定依赖并运行完整检查，不要求用户手动输入命令。
